# 🎯 Main Modules

# 🔢 Matrix Operations Module

A complete matrix utility system with many mathematical operations.

## ✅ Features

* 🎲 Generate random matrices
* ➕ Matrix summation
* ✖️ Matrix multiplication
* 🔄 Matrix transpose
* 🔍 Search inside matrices
* 📊 Sum rows and columns
* 📈 Find maximum and minimum values
* 🧮 Count odd and even numbers
* 🪞 Check identity matrices
* 📐 Check scalar matrices
* ⚡ Matrix comparisons

---

# 🔤 String Utilities Module

A custom string processing library built manually for learning purposes.

## ✅ Features

* 🔠 Uppercase & lowercase conversion
* 🔢 Character counting
* 📚 Word counting
* 🔄 Reverse strings
* ✂️ Split strings
* 🔍 Search inside text
* 🧹 Remove punctuation
* ✨ Trim spaces
* 🔁 Replace words
* 🔐 Encrypt & decrypt text
* 🪞 Palindrome checking

---

# 👤 Client Management System

Simple banking-style client management system using text file storage.

## ✅ Features

* ➕ Add new clients
* ❌ Delete clients
* ✏️ Update client data
* 🔎 Search for clients
* 💾 Save data into files
* 📂 Read & write files
* 📋 Display client information

## 🧾 Client Information

Each client contains:

* 🆔 Account Number
* 🔐 PIN Code
* 👤 Full Name
* 📱 Phone Number
* 💰 Account Balance
